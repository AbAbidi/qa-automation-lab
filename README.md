\# QA Automation Lab



Projet QA Lab.



\## Objectif



Realiser  les tests web, les tests API et les contrôles SQL

sur une instance locale d’OWASP Juice Shop.



\## Outils prévus



\- Java, Selenium WebDriver et TestNG

\- Cypress et Playwright

\- Postman

\- SQL avec SQLite

\- Git et GitHub Actions



\## État du projet



Initialisation du dépôt. Les tests seront ajoutés progressivement.
